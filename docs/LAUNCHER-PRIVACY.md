# Launcher for Android: privacy policy draft

Review before hosting this as a public page on Kevlog. Confirm the support contact, actual network requests, and the Kevlog site's operational logging against the exact Play bundle before removing this draft marker or answering Google Play's Data Safety form.

Launcher is an Android home-screen app. This policy covers the phone edition distributed on Google Play as com.kevlog.launcher.

## Information used on the device

Launcher uses installed-app information to display your home screen, drawers and app results. It stores your layout, preferences, and content you create in Launcher on your device. If you enable notification access in Android, Launcher can display notification information, including message previews, and pass supported actions back to the originating app. Leaving that access off does not prevent you from using the home screen. Optional permissions enable specific features such as weather location, upcoming calendar entries, network device details and reminders.

## Network requests and external services

Features that use the internet connect to the relevant service. These include weather and place lookup using Open-Meteo, news feeds you enable, a web search provider you choose, and the sources you select for downloads. These services receive details needed to respond, such as a weather location, feed address, search query or download URL, along with connection information. Optional offline model packs are downloaded from their hosting source; installing one is separate from running it. Opening Google Discover connects to the Google app. A deliberately configured desktop companion or export destination receives the content you choose to share or save there.

## Your choices

Use Android settings to revoke optional permissions or clear Launcher storage. Clearing app storage removes data held by Launcher, but not files you exported or saved elsewhere. Launcher uses Android's file picker for files outside its app-scoped storage. Google Play supplies updates for this edition.

For privacy questions, contact the developer using the support contact on the Google Play listing.
