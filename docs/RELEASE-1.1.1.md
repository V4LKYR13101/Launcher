# Launcher 1.1.1, build 4

13 November 2026.

This release includes the 1.1.0 app-lock, grayscale, layout and icon work, plus:

- Full-tile fingerprint ridges across standard, compact, wide and tall tiles.
- Stable wallpaper window opacity and preference-only wallpaper flag changes.
- Correct punctuation in Settings, Root and widget options. The source files
  use explicit UTF-8 encoding; the editor configuration preserves it.
- Correct Focus descriptions and the actual installed version in the About text.
- A new build number so installations of development build 3 can update normally.

Release compilation is the validation for this delivery. Functional testing is
left to the owner, as requested. No phone install or tests are part of the final
delivery; the owner will use Settings → App updates.

The publication receipt records the new APK hash, download URL and the old live
APK removed. Private rollback backups remain outside the download service.
