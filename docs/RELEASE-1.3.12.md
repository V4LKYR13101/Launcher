# Launcher 1.3.12 (22)

The final 360 x 640 dp, 150% text screenshot exposed a single-word app label wrapping its last letter onto a second line. Single-word app names now stay on one line and ellipsize when needed. Multiword names retain two-line labels. App search uses the same rule. Full names remain in accessibility descriptions and app controls.

All wider UI refinements from 1.3.11 are retained. Validation includes release compilation, signing continuity and a fresh native small-screen capture. No physical phone used.
