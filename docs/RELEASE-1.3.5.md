# Launcher 1.3.5, build 15

14 November 2026. Feed controls and spacing.

- Feed preferences are available through the main Settings menu as News & feeds, with source count, initial story count and image state shown in its subtitle.
- Removed Refresh and Feed settings buttons beneath the articles.
- Added a small accent refresh icon at the right of the card heading, with a 44 dp touch target and an indeterminate spinner during updates.
- Refresh remains independent of header folding, including when the card is collapsed.
- Show more is centred and is the only button beneath the feed stories. No empty action row is added when all stories are visible.
- Empty-feed guidance points to Settings without adding a card button.
- The story-count editor uses a numeric keyboard and specific instructions.
- Saved stories and existing image settings remain unchanged.

No functional or device tests were run, at the owner's request.

Release compiled with zero warnings and zero errors. Package/version/signing identity, public updater/APK, previous APK removal, release notes, article, gallery preview and retained companion download were verified. The layout illustration was inspected separately from native device testing.
