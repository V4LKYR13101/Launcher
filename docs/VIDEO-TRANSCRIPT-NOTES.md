# Caption access and timestamped notes

Source: [TechAltar video](https://www.youtube.com/watch?v=VVnmrUmSvqo),
4 April 2020, 11:21.

English automatic captions were retrieved directly from the video's caption
track and read for the comparison. Metadata exposed no manually supplied subtitle
track. The notes below are paraphrases, not a verbatim transcript. Proper names
such as Blloc, Qwant and Root were checked against the visible interface because
automatic captions frequently misrecognise them.

The available caption transcript can also be read through
[Filmot's indexed transcript](https://filmot.com/sidebyside/VVnmrUmSvqo/auto.en/auto.en/English%2B%28auto-generated%29/English%2B%28auto-generated%29/Ratio%2Bhands-on%3A%2Bthe%2Bultimate%2BAndroid%2Blauncher/TechAltar).
YouTube's own Show transcript option is available where its interface exposes the
automatic English track. A full copyrighted transcript is not reproduced here.

|---|---|
